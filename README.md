## 🌟 أبرز ميزات الموقع

- **الاستعلام الفوري والسريع**: بحث فوري بالاسم أو رقم الجلوس في أقل من **0.5 ملي ثانية** لقاعدة بيانات تضم **919,396 طالب وطالبة**.
- **النسبة المئوية الموثقة**: حساب وتصدير النسبة المئوية الدقيقة لكل طالب بناءً على المجموع الكلي (من 320 درجة).
- **روابط نتائج مباشرة (Direct Shareable URLs)**: إمكانية إرسال ومشاركة رابط مباشر لكل طالب عبر رقم الجلوس (مثال: `?seating=280145`) ليفتح الشهادة فوراً.
- **معالجة الهمزات الذكية**: مطابقة الأسماء بحرية وتجاهل اختلاف الهمزات (مثل: `أحمد`، `إحمد`، `احمد`).
- **طباعة وتصدير النتائج**: طباعة شهادات رسمية موثقة وتصدير نتائج البحث إلى ملفات **CSV** بترميز UTF-8.
- **توافق كامل مع كافة الهواتف والشاشات**: تصميم متجاوب يعتمد أحدث معايير **Silicon Valley Responsive Design**.
